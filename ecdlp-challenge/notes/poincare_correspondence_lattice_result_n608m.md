# Result: N608M rejects degree two in the declared correspondence lattice

For the explicit N608J maps, restrict to the integral family

```text
u_(a,b) = ((a phi_11 + b pi), pi).
```

The exact H018 pullback degree is

```text
99 a^2 + 27 ab + 81 b^2 - 195 a - 9 b + 99.
```

Modulo nine this is `3a`, so it cannot equal two for any integers `a,b`.
The degree-three N608J pair `(a,b)=(1,0)` is the least positive value in the
declared wide exact window. The degree `17`, `23`, and `41` maps replay on all
109 rational cover points as the corresponding lattice combinations (up to the
codomain sign), so the screen covers the nearby maps already exposed by the
isogeny search.

This is a negative result for the declared integral correspondence lattice,
not for other correspondences or for elementary modifications. It provides no
sections, factor base, relations, rank, descent, cost comparison, or ECDLP
speedup claim.
