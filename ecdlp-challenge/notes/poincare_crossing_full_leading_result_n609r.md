# N609R Result: full corrected-basis crossing coefficient

N609R supersedes the *full-leading-coefficient interpretation* of N609Q.
The corrected Cauchy basis contributes `-r8/u` to the P-origin `x^4`
coefficient, so the full value is `r7-r8/u=moving7`, not `r7` alone.
For levels `0,1,17`, `-det(V_Q)moving7` is Q-regular with constant `31`.
Thus the crossing remains nonzero, but the earlier shortcut value `86` must not
be used as the determinant's full P-origin leading coefficient.
